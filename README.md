# Нотная тетрадь

Built web app for writing violin parts on iPhone. This repository holds only the published build for GitHub Pages; the source lives elsewhere.

Open https://alex-drop2201.github.io/notnaya-tetrad/ in Safari on iPhone, then Share → Add to Home Screen.

Credits: violin samples FluidR3 GM (Frank Wen, CC BY 3.0) via MIDI.js Soundfonts; engraving VexFlow (MIT); PT Serif (ParaType, OFL).

# Нотная тетрадь

Web app for writing violin parts on iPhone. **This branch (`main`) holds only the published build for GitHub Pages.** The source code is in the [`source`](https://github.com/alex-Drop2201/notnaya-tetrad/tree/source) branch of this repository.

Open https://alex-drop2201.github.io/notnaya-tetrad/ in Safari on iPhone, then Share → Add to Home Screen.

To change the app, work in the `source` branch and run `npm run deploy` there — see its README.

Credits: violin samples FluidR3 GM (Frank Wen, CC BY 3.0) via MIDI.js Soundfonts, with the vibrato removed, tuned to A440 and lengthened (see `scripts/samples` in the `source` branch); engraving VexFlow (MIT); PT Serif (ParaType, OFL).
